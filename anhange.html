    14. Anhänge

    14.1. Installation von Node.js

    [Node.js] wird von nodejs.org heruntergeladen: Wählen Sie die LTS-Version (Long-Term Support), zum Zeitpunkt der Erstellung Version 24. Das [Windows]-Installationsprogramm installiert auch [npm]. [Node.js] wird sowohl für die [Ionic]-Projekte ([Angular CLI] 22 erfordert Version 22.22 oder höher) als auch für den JSON-Server benötigt. Überprüfen Sie die Installation in einer Konsole:

    1
2
    node --version
npm --version

    Benötigt ein anderes Projekt eine ältere Version von [Node.js], erlaubt es ein Versionsmanager, mehrere Versionen zu installieren und zwischen ihnen zu wechseln: [nvm-windows] unter [Windows], [nvm] unter [Linux] und [macOS] ([nvm install 24], dann [nvm use 24]).

    Unter [Windows] verweigert [PowerShell] möglicherweise die Ausführung der Befehle [npm] und [npx] („Skriptausführung ist auf diesem System deaktiviert“): Der Befehl [Set-ExecutionPolicy -Scope CurrentUser RemoteSigned] aktiviert sie für den aktuellen Benutzer.

    14.2. Installation von Android Studio und eines Emulators

    [Android Studio] kann von developer.android.com/studio heruntergeladen werden. Es dient nicht zum Schreiben von Code, sondern zur Installation des SDK und von [Android], zur Bereitstellung eines JDK und zum Erstellen eines Emulators (Details finden sich im Kapitel „Einrichtung der Entwicklungsumgebung“):

    • Beim ersten Start installiert der Assistent das SDK und [Android];
    • Menü „More Actions“ / „SDK Manager“, Registerkarte „SDK Tools“: „Android SDK Platform-Tools“ ([adb]), „Android Emulator“ und „Android SDK Command-line Tools“ aktivieren;
    • die Umgebungsvariablen [ANDROID_HOME] (der SDK-Ordner) und [JAVA_HOME] (der Unterordner [jbr] von [Android Studio]) anlegen, die [Capacitor] zum Erstellen der Anwendung benötigt;
    • Menü „More Actions“ / „Virtual Device Manager“: Erstellen Sie ein virtuelles Telefon (zum Beispiel ein „Pixel“) mit einem aktuellen System-Image. Ein Klick auf die Schaltfläche ▶ startet es; [adb devices] erkennt es dann unter dem Namen [emulator-5554]. Sie können es auch starten, ohne [Android Studio] zu öffnen: [npx cap run android] listet die von Ihnen erstellten Emulatoren auf – auch wenn sie gestoppt sind – und startet den ausgewählten; oder über die Befehlszeile das Programm [emulator] des SDK: [emulator -list-avds] listet die Namen der Emulatoren auf, und [emulator -avd <name>] startet einen davon (unter [Windows]: [%ANDROID_HOME%\emulator\emulator.exe]).

    Bei einem echten Telefon: Unter Settings / About Phone schaltet siebenmaliges Tippen auf „Build Number“ die „Developer Options“ frei, in denen sich „USB Debugging“ aktivieren lässt. Beim Anschluss an den Computer fragt das Telefon, ob Sie den Computer autorisieren; [adb devices] erkennt es dann.

    Das [Android]-Projekt, das von [Capacitor] erstellt wurde (der Ordner [android/]), öffnet sich in [Android Studio] über [npx cap open android]. Es enthält unter anderem das Fenster [Logcat] (Anwendungs- und Systemmeldungen, einschließlich der Meldungen der [Capacitor]-Plugins) und die Schaltfläche [Run], die dasselbe bewirkt wie [npx cap run android].

    14.3. Installation von Visual Studio Code

    [Visual Studio Code] wird von code.visualstudio.com heruntergeladen. Die Unterstützung für [TypeScript] und [JavaScript] ist bereits integriert. Installieren Sie im Bereich „Extensions“ (Strg+Umschalt+X) Folgendes:

    • die Erweiterung [Angular Language Service] (vom [Angular]-Team): Autovervollständigung und Validierung in Templates ([HTML] – Eigenschaften und Methoden der Klasse, Inputs der Komponenten und Attribute der Komponenten von [Ionic]), Navigation von einem Template zum Klassencode (F12) und Anzeige von Template-Kompilierungsfehlern während der Eingabe;
    • die Erweiterung [Ionic] (vom [Ionic]-Team): ein Bereich, der die Anwendung im Browser oder auf einem [Android]-Gerät startet, die Plugins für [Capacitor] verwaltet und über Aktualisierungen der Pakete [Ionic] und [Capacitor] informiert;
    • optional die Erweiterung [Prettier], die den Code beim Speichern gemäß den Regeln formatiert, die in der Datei [.prettierrc] der Projekte festgelegt sind.

    Öffnen Sie ein Projekt über das Menü File / Open Folder (zum Beispiel den Ordner [examples_ionic]) und eine Konsole über das Menü Terminal / New Terminal; dort geben Sie [npm install], [npm start], [npx ng build], [npx cap run android] usw. ein. Die Datei [.vscode/launch.json] in den Projekten erlaubt es außerdem, die Anwendung über F5 zu starten: [VS Code] führt dann [npm start] aus, öffnet [Chrome] mit der Anwendung, und Sie können Haltepunkte direkt im [TypeScript]-Code im Editor setzen.

    14.4. Entwicklertools von Chrome

    Die Entwicklertools von [Chrome] sind für eine [Ionic]-Anwendung das, was [Flutter DevTools] für eine [Flutter]-Anwendung sind. Sie lassen sich mit F12 (oder Strg+Umschalt+I) öffnen. Die nützlichsten Registerkarten sind:

    • die Geräteemulationsleiste (Strg+Umschalt+M): die auf die Größe eines Telefons skalierte Anwendung (ein Modell aus der Liste oder frei gewählte Abmessungen), mit Touch-Ereignissen. So entwickeln Sie die Anwendung, bevor Sie zu [Android] wechseln;
    • „Elements“: der Elementbaum der Seite und für jedes Element seine Stile (die sich in Echtzeit bearbeiten lassen). Mit dem Pfeilsymbol in der oberen linken Ecke können Sie auf ein Seitenelement klicken, um es im Baum zu finden. Dort sehen Sie die Tags [<ion-...>] und in jedem von ihnen sein „Shadow DOM“: die HTML-Elemente, aus denen es besteht. Dieses Werkzeug beantwortet die Frage: „Warum sitzt dieses Element nicht an der richtigen Stelle?“;
    • „Console“: die Meldungen ([console.log()]) und Fehler der Anwendung, zusammen mit Datei und Zeile ([TypeScript]), in denen sie aufgetreten sind;
    • „Sources“: der Anwendungscode ([TypeScript]) (mithilfe der Source Maps aus der Konfiguration [development]), in dem die Haltepunkte gesetzt werden;
    • „Network“: die Anfragen (HTTP) der Anwendung samt ihren Headern und Bodys: Hier sehen Sie, wie das Token-Cookie gesendet und empfangen wird (im Browser);
    • „Application“: der Speicher der Seite ([localStorage], in dem das Plugin [@capacitor/preferences] seine Werte in einem Browser ablegt) und ihre Cookies.

    Die Erweiterung [Angular DevTools] (zu installieren aus dem [Chrome Web Store]) fügt eine Registerkarte „Angular“ hinzu: den [Angular]-Komponentenbaum des Bildschirms und für jede Komponente ihre Inputs, Signals und Eigenschaften, die sich in Echtzeit ändern lassen; die Registerkarte „Profiler“ zeigt, was [Angular] nach jedem Ereignis aktualisiert hat – und wie lange das gedauert hat.

    Dieselben Werkzeuge können die auf dem Emulator oder auf dem Telefon installierte Anwendung debuggen. Öffnen Sie im [Chrome] auf dem Computer die Adresse [chrome://inspect]: Die Seite listet die über [adb] verbundenen Geräte auf und für jedes davon die WebView der aktuell laufenden Anwendungen, die debuggt werden dürfen (das gilt für [Capacitor]-Anwendungen, die im „debug“-Modus erstellt wurden, etwa mit [npx cap run android]). Der Link „Inspect“ öffnet ein Entwicklertools-Fenster, das mit der WebView der Anwendung verbunden ist und links den Bildschirm des Telefons zeigt: Hier finden Sie die Registerkarten „Elements“, „Console“, „Sources“, „Network“ und weitere ... Da die Anfragen von [CapacitorHttp] über den nativen Code von [Android] laufen, erscheinen nicht alle auf der Registerkarte „Network“: Das Fenster [Logcat] von [Android Studio] zeigt sie an.

    14.5. Installation von MySQL mit Laragon

    Der JSON-Server benötigt [MySQL] (oder [MariaDB]). [Laragon] (laragon.org) installiert unter [Windows] eines davon gebrauchsfertig, zusammen mit dem Verwaltungswerkzeug [HeidiSQL]. Nach der Installation:

    • die Schaltfläche „Start All“ startet den [MySQL]-Server auf Port 3306;
    • der Benutzer [root] hat kein Passwort: Das sind die Standardwerte aus der Datei [.env.example] des Servers;
    • In [HeidiSQL] (Schaltfläche „Database“) führt der Menüeintrag File / Run SQL das Skript [database/dbrdvmedecins2.sql] aus.

    Installieren Sie unter [Linux] oder [macOS] [MySQL] oder [MariaDB] mit dem Paketmanager des Systems und führen Sie das Skript mit dem Befehlszeilenclient aus: [mysql -u root -p < database/dbrdvmedecins2.sql].

    14.6. Installation von curl

    [curl] ist in [Windows] 10 und 11, [macOS] und den meisten [Linux]-Distributionen enthalten. Prüfen Sie die Version:

    1
    curl --version

    Die Option [--json] (in diesem Dokument verwendet) gibt es seit Version 7.82 (2022). Wenn Sie eine ältere Version verwenden, ersetzen Sie [--json @file] durch [-H "Content-Type: application/json" -d @file] oder installieren Sie eine aktuelle Version ab curl.se.

    Geben Sie in [PowerShell] bitte [curl.exe] ein, nicht [curl]: In [PowerShell] ist [curl] ein Alias für einen anderen Befehl ([Invoke-WebRequest]), der die Optionen von [curl] nicht kennt. Die Eingabeaufforderung ([cmd]) hat dieses Problem nicht.
